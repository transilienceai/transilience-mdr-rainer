# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in this repository, report it privately.

Do not open a public GitHub issue for:

- Credential exposure.
- Customer evidence exposure.
- Unsafe default configurations.
- Dependency or supply-chain concerns.
- Scripts that could mishandle sensitive telemetry.

Email [contact@transilience.ai](mailto:contact@transilience.ai) with:

- Description of the issue.
- Affected files or components.
- Steps to reproduce, using synthetic data where possible.
- Potential impact.
- Suggested fix, if available.

## Scope

This policy covers vulnerabilities in this repository, including:

- MDR skills and references.
- Python scripts.
- Examples and documentation.
- CI/CD configuration.
- Plugin and marketplace metadata.

## Responsible Use

This project is for authorized MDR, detection engineering, and incident response. Users are responsible for obtaining permission before collecting or analyzing cloud telemetry and for complying with all applicable laws and agreements.
