# VPC Flow AI Report Template

Use this structure when editing generated Markdown:

1. Title and reporting window.
2. Executive summary with total candidates, top workloads, and strongest evidence.
3. Priority actions with owner-ready remediation language.
4. Provider and model-path evidence.
5. RAG/vector and internal inference candidates.
6. Agent-like fanout and timing evidence.
7. Bedrock attribution.
8. Limitations and follow-up telemetry.
9. Evidence appendix listing generated CSV and JSON files.

Keep claims tied to generated artifacts. Do not state exact SaaS model, prompt content, or exfiltration unless supporting telemetry outside VPC Flow Logs was reviewed.
