# Weekly Report Template

Use this structure when editing generated Markdown:

1. Title and reporting window.
2. Executive summary with total finding counts and the strongest evidence source.
3. Priority actions with owner-ready remediation language.
4. Shadow AI and OAuth section with confidence levels.
5. Drive exposure section with external grants/downloads/access requests.
6. Login and authentication section with risky events and notable failure clusters.
7. Admin and configuration section with high-risk changes and usage snapshot metrics.
8. Evidence appendix listing generated CSV and JSON files.

Keep claims tied to generated artifacts. Do not state that an app is currently allowed, blocked, or trusted unless current Admin Console state was validated.
