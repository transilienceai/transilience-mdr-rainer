# Configuration Metrics

Track these metrics across Git AI reports:

- Total repositories scanned.
- Total files scanned.
- Total AI findings.
- Findings by confidence.
- Findings by risk category.
- Repositories with confirmed code usage.
- Repositories with MCP configuration.
- Repositories with prompt, eval, or training artifacts.
- Repositories with RAG/vector-store indicators.
- Repositories with CI/CD AI usage.
- Repositories with secret-name indicators.

Use deltas week over week to identify new AI adoption, new MCP exposure, and newly introduced provider dependencies.
