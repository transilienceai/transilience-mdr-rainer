# Git AI Security Report Template

Use this structure when editing generated Markdown:

1. Title and reporting window.
2. Executive summary with total finding counts and strongest evidence.
3. Priority actions with owner-ready remediation language.
4. Model/provider section with confidence levels.
5. Agent framework and MCP section with tool-exposure risks.
6. Prompt, RAG, vector, training, and eval section.
7. Supply-chain and CI/CD section.
8. Evidence appendix listing generated CSV and JSON files.

Keep claims tied to generated artifacts. Do not claim runtime usage unless source evidence supports direct code/config usage or runtime telemetry was reviewed separately.
